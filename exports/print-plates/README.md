# print plates

for my P1S with a 0.4 mm hardened-steel nozzle and textured PEI plate. plates 1-6 make the general-purpose vise. plate 7 is only for the optional ESC adapters

start with the fit samples and one grip pair during build week before printing the whole set

| [07-optional-esc-adapters](07-optional-esc-adapters.3mf) | PETG-CF | 0h 46m | 16 g |

about 729 g of PETG-CF and 116 g of TPU for the general-purpose vise. the ESC adapters add about 16 g of PETG-CF. these are slicer estimates, before fit samples or failed prints

the rigid parts use 0.20 mm layers, four walls and 30% gyroid infill. the TPU parts use three walls and 15% infill

only the feet have supports enabled. clean them out of the side slots and nut pockets before assembly. the right-hand base bars print top face down; the TPU grips print rail underside down

open a project, check the material and plate, then slice again before printing. nothing has been printed yet
